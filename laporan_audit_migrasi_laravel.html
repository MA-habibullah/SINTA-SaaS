1. Perbandingan Arsitektur: Native Saat Ini vs Laravel 11 Modular
Structural Mapping
Arsitektur SINTA Saat Ini (PHP Native OOP)
  • Routing Monolitik: Satu berkas index.php berisi 3.266 baris kode mapping URL, switch-case, dan middleware manual.
  • Model & Database: Model kustom memanggil PDO::prepare() manual dengan raw SQL string di setiap function.
  • Multi-Tenancy: Validasi tenant_id manual di setiap SQL query dan filter file guard.
  • Autentikasi & Sesi: Dikelola manual via SessionManager.php dan query session tracking sendiri.
  • Validasi Input: Pengecekan manual di controller via $_POST, strip_tags(), dan filter_var().
  • Background Queue: Skrip CLI polling manual di worker.php dengan loop sleep(5).
  • Frontend Views: File PHP view memuat Vue 3 via script global CDN dengan JavaScript inline yang sangat panjang.
Target Arsitektur: Laravel 11 + Modular Engine
  • Routing Terisolasi per Modul: Masing-masing modul memiliki berkas Routes/web.php dan Routes/api.php sendiri.
  • Eloquent ORM & Relations: Query SQL manual digantikan Eloquent Model lengkap dengan relasi hasMany, belongsTo, dan Type Casting.
  • Multi-Tenancy Otomatis: Menggunakan package stancl/tenancy (auto-schema switching PostgreSQL & auto-tenant storage).
  • Enterprise Auth & RBAC: Menggunakan Laravel Sanctum / Session Auth + spatie/laravel-permission (9 Role).
  • Form Request Validation: Validasi otomatis terpisah (StoreSiswaRequest) dengan response JSON 422 terstandarisasi.
  • Queue & Horizon: Background jobs diproses via php artisan queue:work (Redis) dengan auto-retry & failed job log.
  • Vite + Vue 3 / Inertia: UI Vue 3 di-compile bersih via Vite (Single File Component .vue) atau disatukan via Inertia.js.

2. Rincian 16 Aspek Teknis yang Perlu Dibenahi & Diadaptasi
Comprehensive 16-Area Audit
Komponen Sistem Kondisi Saat Ini & Area Perbaikan Solusi & Implementasi di Laravel 11
1. Entry Point & Routing Monolitik Berkas index.php berukuran 133 KB (3.266 baris) menampung seluruh rute URL, pengecekan guard, switch-case, parsing path manual, dan exception handler.
Perlu Dirombak Total 		Hapus file index.php monolitik. Pecah rute ke masing-masing modul: Modules/Siswa/Routes/web.php, Modules/Keuangan/Routes/api.php, dll. Pengecekan hak akses dialihkan ke **Laravel Route Middleware**.
2. Database Access & Eloquent ORM Model di app/Modules/[Modul]/Models masih menggunakan raw query PDO manual (SELECT * FROM ...). Relasi tabel ditulis manual.
Perlu Konversi ke Eloquent 		Konversi Model menjadi **Eloquent Model**:
  • Deklarasi tabel dengan skema: protected $table = 'akademik.kelas';
  • Definisi relasi: public function siswa() { return $this->hasMany(Siswa::class); }
  • Gunakan Global Scope BelongsToTenant untuk auto-filter tenant_id.
3. Multi-Tenancy & Schema Isolation Pengecekan tenant_id dilakukan manual di setiap fungsi query dan file guard kustom (RouteGuard.php & StorageGuard.php).
Perlu Standarisasi Package 		Gunakan package **`stancl/tenancy`** atau **`spatie/laravel-multitenancy`**. Sistem secara otomatis mengubah PostgreSQL search_path per request tenant dan mengisolasi direktori upload storage.
4. Autentikasi & RBAC (9 Role) SessionManager.php mengelola cookie, token CSRF, fingerprint perangkat, dan status multi-role secara kustom.
Ganti dengan Laravel Auth 		Gunakan **Laravel Native Session / Sanctum** + package **`spatie/laravel-permission`**. Pemeriksaan hak akses di Controller / View menjadi sangat mudah: $user->hasRole('guru') atau @can('input-nilai').
5. Validasi Input (Form Request) Validasi manual di dalam function Controller menggunakan $_POST, filter_var(), dan isset() bercampur dengan logika bisnis.
Pisahkan ke Form Request 		Gunakan **Laravel Form Request Validation**: StoreSiswaRequest, UpdateNilaiRequest. Validasi otomatis mengecek format data, aturan unique multi-tenant, dan auto-return error JSON 422.
6. Standarisasi API Response & Resources Controller me-return array manual via $this->jsonResponse(['success' => true, ...]) dengan mapping data kustom.
Adaptasi ke API Resources 		Gunakan **Laravel API Resources (JsonResource / Transformers)**. Data sensitif (seperti password hash, salt, internal token) disembunyikan secara deklaratif di Resource layer.
7. Format Migrasi Database (55 File) 55 file di database/migrations/ menggunakan format closure kustom return ['up' => function(PDO $pdo)...].
Perlu Format Ulang Migrasi 		Konversi ke format standar **Laravel Migration Class**: Schema::create('siswa.buku_induk', function(Blueprint $table)...) agar dapat dikelola via command php artisan module:migrate.
8. Background Queue & Jobs (worker.php) worker.php adalah daemon CLI polling manual dengan loop sleep(5) yang rentan mati jika terjadi memory limit.
Ganti dengan Laravel Queue 		Ubah tugas berat (Generate Tagihan SPP Massal, Bulk Print Rapor, Ekspor Excel) menjadi **Laravel Jobs** (GenerateTagihanJob) yang dijalankan via php artisan queue:work (driver Redis/Database) + monitoring **Laravel Horizon**.
9. Modernisasi Frontend (Vue 3 + Vite / Inertia) File di views/ memuat Vue 3 via CDN Global Build dengan script inline JS di bawah HTML PHP (misal: file master_bk.php berukuran 489 KB).
Modernisasi ke SFC / Inertia 		Pisahkan menjadi **Vue 3 Single File Components (.vue)** di dalam resources/js/Pages/. Gunakan **Vite** untuk build minified bundle dan **Inertia.js** agar Controller langsung merender view tanpa perlu memisahkan backend-frontend secara rumit.
10. Spreadsheet Excel Import / Export Menggunakan SimpleXLSX & SimpleXLSXGen secara prosedural di dalam controller.
Upgrade ke Laravel Excel 		Gunakan package **`maatwebsite/excel`**. Mendukung *Chunk Reading*, *Queueable Exports*, dan *Batched Imports* sehingga import ribuan data siswa/nilai tidak pernah mengalami timeout.
11. Generator Dokumen & Cetak PDF Eksekusi Node.js Puppeteer manual via script command line exec().
Integrasi Browsershot / Snappy 		Gunakan package **`spatie/laravel-browsershot`** atau **`barryvdh/laravel-snappy`**. Terintegrasi langsung dengan background queue worker untuk cetak rapor massal 1 sekolah tanpa membebani web server utama.
12. Single Session & Device Management Perekaman session aktif dilakukan manual via App\Helpers\SessionTracker.php dan tabel core.active_sessions.
Ganti Middleware Native 		Gunakan session driver database bawaan Laravel + middleware AuthenticateSession untuk otomatis meng-kick login di perangkat lain saat password diganti.
13. Rate Limiting & Proteksi DDoS Belum ada proteksi rate limiter pada endpoint API login dan eksekusi transaksi keuangan.
Wajib Ditambahkan 		Gunakan **Laravel Rate Limiter** (RateLimiter::for('api', ...) & throttle:60,1) untuk mencegah brute-force login dan abuse pada API endpoint.
14. Storage Quota & File Upload Guard Pengecekan batas kuota penyimpanan sekolah dihitung manual via iterasi direktori di StorageGuard.php.
Middleware Storage Quota 		Gunakan Middleware Laravel CheckTenantStorageQuota yang memeriksa kolom core.tenants.storage_used_bytes sebelum file disimpan ke Storage::disk('tenant').
15. Centralized Error Tracking & Sentry APM Error tracking PHP disimpan di tabel sistem.system_errors dan JS error dikirim via sendBeacon.
Upgrade ke Monolog / Sentry 		Gunakan **Laravel Exception Handler (Monolog)** + integrasi **Sentry / Bugsnag** dan **Laravel Telescope** untuk diagnostik error server secara real-time.
16. Testing Suite (Automated QA) Pengujian saat ini berupa 360+ berkas script uji mandiri di folder scratch/pengujian/test_*.php.
Standarisasi ke PHPUnit / Pest 		Konversikan menjadi **Pest PHP / PHPUnit Feature Tests** terstruktur di Modules/[Modul]/Tests/Feature/ yang dapat dijalankan otomatis sekali jalan via php artisan test.
3. Rencana Eksekusi Migrasi Bertahap (Step-by-Step Migration Phases)
Roadmap Eksekusi
FASE 01
Inisialisasi Project Laravel 11 & Package Setup

Membuat fondasi proyek Laravel 11 baru dan memasang package-package inti yang dibutuhkan untuk arsitektur modular & multi-tenant.

Command Utama:
composer create-project laravel/laravel sinta-v2
composer require nwidart/laravel-modules stancl/tenancy spatie/laravel-permission maatwebsite/excel spatie/laravel-browsershot
npm install vue @vitejs/plugin-vue @inertiajs/vue3 tailwindcss bootstrap bootstrap-icons
FASE 02
Konfigurasi Database Multi-Schema & Porting Migrasi

Menghubungkan koneksi PostgreSQL ke 16 skema yang sudah ada (search_path) dan mengonversi berkas migrasi database ke dalam format Laravel Migration per-modul.

• Konfigurasi config/database.php driver PostgreSQL dengan 16 skema.
• Generate struktur modul menggunakan command: php artisan module:make Siswa, php artisan module:make Akademik, php artisan module:make Keuangan, dll.
FASE 03
Porting Model & Logic Bisnis (Eloquent + Form Request + RBAC)

Memindahkan logika controller dan model dari folder app/Modules/ lama ke folder Modules/[Modul]/ Laravel, serta mendefinisikan relasi Eloquent dan role permission.

• Pindahkan logika perhitungan Rapor, Ledger, SPP, Konseling BK, dan Algoritma Simulasi PDSS.
• Terapkan Middleware Tenancy & RBAC Guard pada route masing-masing modul.
FASE 04
Modernisasi Frontend Vue 3 + Inertia / Vite & Integrasi UI

Mengonversi tampilan view PHP yang memuat Vue inline menjadi komponen Vue 3 Single File Component (.vue) yang rapi, cepat, dan terkompilasi bersih via Vite.

• Mempertahankan seluruh desain styling Bootstrap 5.3 + Tailwind CSS dan NavTab scroller yang sudah ada.
• Integrasi Inertia.js untuk pertukaran data backend-frontend yang sangat cepat dan bebas error script leak.
FASE 05
Pengujian Menyeluruh (Pest / PHPUnit) & Switch Produksi

Menjalankan pengujian fitur secara menyeluruh (CRUD Siswa, Ledger Rapor, Cetak PDF Puppeteer, Kasir SPP, dan Simulasi PDSS), validasi isolasi data tenant, dan deployment ke server produksi.
