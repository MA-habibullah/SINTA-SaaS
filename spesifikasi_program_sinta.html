1. Ringkasan Eksekutif & Identitas Platform
SaaS Multi-Tenant
Nama Resmi Aplikasi SINTA-SaaS (Sistem Informasi Nilai dan Tata Kelola Akademik Terintegrasi)
Model Bisnis / Arsitektur Software-as-a-Service (SaaS) Multi-Tenant Shared Database dengan partisi 16 skema terpisah di PostgreSQL dan isolasi kolom tenant_id.
Cakupan Institusi Dukungan penuh untuk seluruh jenjang pendidikan dasar dan menengah: SD / MI, SMP / MTs, SMA / MA, dan SMK / MAK (dilengkapi modul Vokasi/PKL DUDI).
Peran Pengguna Utama
1. Super Admin Platform 2. Admin / Operator Sekolah 3. Kepala Sekolah 4. Guru Mata Pelajaran 5. Wali Kelas 6. Guru Bimbingan Konseling (BK) 7. Staf Tata Usaha / Keuangan / Perpus / Sarpras 8. Siswa 9. Orang Tua / Wali Murid
2. Spesifikasi Teknologi (Technology Stack)
High Performance & Modern
Komponen Teknologi Terpasang Keterangan & Peran Teknis
Backend Engine PHP 8.x Native Modern OOP Arsitektur PSR-4 Modular, Strict Types, tanpa bloating overhead framework, responsif & hemat RAM.
Database Engine PostgreSQL 15+ / 16+ (Fallback MySQL) Multi-Schema (16 skema), Strict Type Casting, Search Path terisolasi, UUID generator v4.
Styling UI Bootstrap 5.3.x + Tailwind CSS UI modern kelas enterprise, preflight disabled untuk mencegah konflik CSS, Google Fonts Plus Jakarta Sans.
Reaktifitas Klien Vue 3 (Composition API) + Axios Pola asynchronous fetch onMounted, Zero Data Leakage pada View Source HTML, CSRF token auto-header.
Navigasi & UX Hotwire Turbo + 3-Way Scroller NavTabs Navigasi instan layaknya Single Page Application (SPA), tab horizontal dapat digeser via wheel mouse, drag, & tombol panah.
Spreadsheet Engine shuchkin/simplexlsx & simplexlsxgen Import & export buku induk, nilai rapor, ledger, katalog buku, dan data presensi format Excel hemat memori.
Cetak PDF / Rapor Puppeteer-core (Node.js) Generator dokumen resolusi tinggi untuk cetak Rapor K13 / Merdeka, Transkrip, Surat Resmi, dan Kartu Pelajar.
Background Worker worker.php (CLI Daemon) Pemroses antrean tugas berat (bulk generate tagihan SPP, sinkronisasi data, import/export massal).

5. Matriks Hak Akses Peran Pengguna (RBAC Permisson Matrix)
Strict Access Control
Peran Pengguna (Role) Cakupan Menu & Fitur yang Dapat Diakses
Super Admin Platform Mengakses 100% seluruh menu dan fitur sistem lintas tenant/sekolah, konfigurasi paket, kelola server, dan database auditor.
Admin / Operator Sekolah Dashboard, PPDB, Data Pokok (Buku Induk, Master Data, Pengguna), Akademik, Keuangan, Perpustakaan, Persuratan, Kesiswaan, BK, Sarpras, Absensi, dan Utilitas Sekolah.
